Running CONTAM

As indicated in the Installing CONTAM section, CONTAM actually consists of two executable programs: ContamW and ContamX. ContamW is the graphical user interface and ContamX is the simulation engine. Typically you will activate ContamX via a menu command from within ContamW. However, ContamX can be utilized as a command-line tool and even utilized within script or batch files.

Running ContamW

Run ContamW by selecting CONTAM #.#.#.# (where # indicate the program version, e.g., 3.4.0.0) from the Start menu.

Running ContamX as a Command-line Program

The easiest way to run ContamX as a command-line program is by copying the contamx3.exe file and related projects and supporting files to a common directory. The options for running ContamX can be shown by typing:

contamx3 --help

This will display the following output:

ContamX - Multizone Airflow and Contaminant Transport Analysis Software

Usage: contam-x [input-file] [options]

-h, --help show this help message and exit

-v, --Version show the version of this program and exit

-b, --Bridge=<str> run ContamX in bridge mode with optional <ip_address:port>

-w, --Wind ContamX calculates wind pressures based on wind speed and

      direction obtained via ADJ_WTH_MSGTYPE

-f, --volumeFlow ContamX outputs volume airflow rates via bridge in [m3/s]

-c, --Console run ContamX with an interactive console

-d, --Dialog run ContamX with a windows dialog box

-t, --TestInput Test input only

[input-file] is a path to a CONTAM PRJ file.

    If omitted with no other options, you will be prompted to enter a file name.

    The file can be specified in Windows Explorer by dragging

    the project file icon onto the ContamX program icon.

Running ContamX with TCP/IP Socket Communication

ContamX can be run in a TCP/IP socket communication mode that enables run-time control over the simulation including execution control and data transfer via TCP/IP sockets. See Appendix B for details and a complete description of the TCP/IP messaging structure.
