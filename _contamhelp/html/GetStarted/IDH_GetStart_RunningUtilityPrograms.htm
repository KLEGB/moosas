Running Utility Programs

These utility programs are provided with ContamW as 32-bit versions for the Windows operating system. They are also available on the NIST Multizone Modeling Website as 64-bit versions for both the Windows and Linux operating systems. Type the following at the command prompt to obtain usage information for each program, respectively:

simread

$ simread

simcomp

$ simcomp

A configuration file (simcomp.cfg) can also be utilized to override the default uncertainty associated with the comparison. If used, the configuration file must be located alongside the simcomp executable. The following example of the simcomp.cfg file provides the default uncertainty values.

1.00e-04 ! epsdP – relative error in link Pressure difference

1.00e-04 ! epsF – relative error in link Flow rate

1.00e-03 ! epsT – absolute error in node Temperature

1.00e-04 ! epsPg – relative error in node gage Pressure

1.00e-05 ! epsD – absolute error in node air Density

1.00e-04 ! epsMf – relative error in node Mass fractions

1.00e-20 ! epsMa – absolute error in node Mass fractions

100 ! nmax – maximum number of failures to report

Where,

erel = |v1-v2|/|v1+v2|

eabs = |v1-v2|

prjup

$ prjup -h
