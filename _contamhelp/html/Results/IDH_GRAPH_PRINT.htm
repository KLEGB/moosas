Print Graph

Graphics Format: There are four graphics formats available for printing charts.

Bitmap: This produces a standard Windows BMP generated at the same color depth as the current user's video mode.

Enhanced Metafile: A simple enhanced Windows metafile.

Aldus-Placeable Metafile: This variety of metafile tends to work better than other metafiles when placing in documents.

Windows Metafile: A standard Windows metafile.

Scale: There are 5 different scaling options available when printing ContamW charts.

No scaling: The image is printed as is with no regard to the paper size.

Scale to width: Scales the width of the chart to match the width of the printout ignoring the height.

Scale to height: Scales the height of the chart to match the height of the printout ignoring the width.

Scale to fit (maintain aspect): Scales the printout to match the size of the printout as closely as possible while maintaining the original aspect ratio.

Scale to fit (ignore aspect): Scales the printout to match the size of the printout as closely as possible with no regard for the original aspect ratio. This option will fit the graph as closely as possible to the page, but may stretch/distort the graph slightly.

Copy to Clipboard: This option allows you to copy the chart data to the clipboard in the above specified format for use in other Windows applications.
