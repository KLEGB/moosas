TRNSYS-CONTAM Utilities and Setup

In addition to Type98, a set of tools was developed to facilitate the TRNSYS-CONTAM coupling process. These tools enable development of coupled building models including the connectivity between the inputs and outputs of Type98 and Type56. The tools are available on the NIST Multizone Modeling website (https://www.nist.gov/el/energy-and-environment-division-73200/nist-multizone-modeling). This section presents the tools and their associated input files along with instructions pertaining to where these files should be located on your Windows system in order to work with TRNSYS. In the file paths below, Trnsys\ refers to the directory into which TRNSYS was installed.

Software Components and Files

Type98<version>.dll

Type98 dynamic link library file developed to TRNSYS specifications. It is the go-between that handles communication of TRNSYS commands and data to/from ContamX. The “<version>” portion of the file name will depend on the versions of TRNSYS and CONTAM and the operating system architecture for which the Type was compiled, e.g., “_t18_c33-x64” indicates the DLL is compatible with TRNSYS version 18, CONTAM version 3.3, and is a 64 bit Windows executable.

Copy the Type98 dll to the Trnsys\Userlib\ReleaseDLLs directory.

ContamX3.exe

This is the calculation engine (solver) of the CONTAM program. It utilizes socket communication to transfer commands and data with Type98. It is installed in the CONTAM installation folder.

Copy ContamX3.exe to the Trnsys\Exe directory.

Type98.bmp

Type98 icon that can be associated with static-dynamic proformas created during CONTAM-TRNSYS coupling method outlined below.

Copy Type98.bmp to the Trnsys\Studio\Proformas\Utility\Calling External Programs\CONTAM directory. This file is not critical, but usage is described in process below.

CONTAM3DExport.exe

This program enables the coupling of TRNSYS with CONTAM. It can be used to create a Trnsys3D file (.idf) by extruding CONTAM project files that have been drawn to scale using the new pseudo-geometry drawing features of ContamW. This tool also generates the files necessary to perform a coupled TRNSYS/CONTAM simulation including:

  • TRNSYS input or deck file (.dck)
  • Type98 dynamic static proforma (.tpf)
  • Type56 building file (.b17)
  • Variable exchange file (.vef)

An installer for CONTAM3DExport is provided on the NIST Multizone Modeling website.

NOTE: The Type56-98Coupler tool is no longer needed for coupling beginning with TRNSYS18. The CONTAM3DExporter now generates a TRNSYS input file directly which includes the connectivity required between the INPUTS and OUTPUTS of Type56 and Type98. However, if the building geometry must be modified, e.g., to create sloped roof surfaces or add shading surfaces, then the coupling procedure provides a method to address these modifications.

Type98.log

This is a log file for Type98 in the same directory as the TRNSYS project file during a coupled simulation. This file will contain information associated with execution of Type98. You can use the logging flag of the vef file (see TRNSYS Input FIles) to provide various levels of details to the Type98.log file that will be created. Set the value between 0 for no logging and 3 for detailed logging.
