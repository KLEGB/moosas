Working with Levels

CONTAM projects are organized by levels. Each level of a CONTAM project contains a plan view drawing. Typically, each level of a CONTAM project corresponds to a floor of a building. Depending on the detail required for your modeling purposes, you could represent a building floor using multiple levels. For example, a level could be used to represent a ceiling or floor plenum.

NOTE: CONTAM provides multiple ways to define rooms that span multiple levels, e.g., an atrium. You can draw the zone on the lowest level that it will exist, and then draw phantom zones on adjacent levels above. This method will create a single zone that spans multiple levels, and the zone will be characterized as having uniform contaminant properties throughout. You could also draw normal zones above one another and place flow paths in the floors between them. Neither of these methods will inherently provide for two-way vertical flows between the zones. If this is necessary, then you might consider defining the zone as a CFD zone.
