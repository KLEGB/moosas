Defining Occupants

After you draw an exposure icon on the SketchPad you must define it using the icon definition procedure (See Defining Building Component Icons) to display and edit the properties. This will display the "Occupant Exposure Properties" dialog box. Detailed descriptions of all occupant exposure properties are given in the following Occupant Properties section. Once you have defined the properties, the icon will be displayed in black. From now on, you use this icon to access the properties of the occupant.
