Cell/Icon Size

Current Cell/Icon Size: There are seven options for displaying icons on the SketchPad (1x1, 2x2, 3x3, 4x4, 5x5, 8x8, and 16x16). The default option is 8x8. This is a "zooming" feature that provides a visual aid to enable you to view sketches in more detail or to fit larger sketches within the program window. The cell size has no effect on the project simulation. There are two "zooming" buttons provided on the toolbar to quickly increase and decrease the cell size according to the available cell sizes below.

Available Cell Sizes: Use these check boxes to select which sizes you want available. The 1x1 size causes problems with some versions of the Window 98 operating system. If this is the case for you, then deselect the 1x1 check box and click the "Save Configuration" button.

Cell Jump: Use this to set the number of SketchPad cells the cursor will jump when you use the Shift + Arrow Keys to maneuver around the SketchPad.
