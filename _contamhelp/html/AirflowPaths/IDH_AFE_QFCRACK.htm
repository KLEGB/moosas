Quadratic Model: Crack Description

This model employs a quadratic relationship of the form DP = aQ + bQ² where Q is the volume flow rate [Baker, Sharples, and Ward 1987]. CONTAM uses the mass flow version of that formula: DP = aF + bF² where DP is the pressure drop and F is the mass flow rate.

Name: Enter the name you want to use to identify the airflow element. The airflow element will be saved within the current project and can be associated with multiple airflow paths.

Crack Dimensions:

Length: The overall length of the crack

Width: Width of the crack

Depth: The distance along the direction of airflow

Number of Bends: The number of bends in the flow path.

Description: Field for entering a more detailed description of the specific airflow element.
