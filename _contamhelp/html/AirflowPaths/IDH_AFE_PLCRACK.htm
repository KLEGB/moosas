Powerlaw Model: Crack Description

This airflow element allows you to enter the description of a crack and is based upon the relationships developed between flow through cracks and the powerlaw model [Clark 1985].

Name: Enter the name you want to use to identify the airflow element. The airflow element will be saved within the current project and can be associated with multiple airflow paths.

Crack Length/Width: Enter the length and width of the crack.

Description: Field for entering a more detailed description of the specific airflow element.

Note: ContamW automatically uses the icon for a small opening for the powerlaw model crack description.
