One-way Flow Using Powerlaw Models

CONTAM performs airflow calculations using the mass flow powerlaw formula, F = C(DP)^n, for the following types of airflow elements. Where F is the mass flow rate, DP is the pressure difference across a flow path, C is the flow coefficient, and n is the flow exponent. However, for some of the powerlaw models, ContamW enables you to input parameters that describe an opening in terms other than the coefficient C and exponent n. These parameters are then converted internally by ContamW to determine C and n for the mass flow version of the powerlaw model.
