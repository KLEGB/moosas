Working with Walls

In ContamW, walls are used to create enclosed regions referred to as zones on a given level. Walls include the building envelope and internal partitions with a significant resistance to airflow. Use the Pseudo-Geometry option to draw models based on scaled geometry (See Project Configuration Properties).

ContamW is not meant to provide drawing capabilities similar to that of a Computer Aided Drawing (CAD) program. The SketchPad drawing functions were designed to provide a strict environment for creating the input to the underlying multizone model upon which the CONTAM simulation engine is based.

ContamW does provide the ability to import an image over which you can draw floorplans. This feature can be useful to establish the basic outlines of the building zones on a given level of a building. Use the commands under the Tools menu item to import a bitmap (.BMP) file onto the SketchPad and manipulate its size and position on the SketchPad (see SketchPad Display under Program Configuration Properties). Wall drawing has been slightly modified in version 3.3 to remove previous restrictions that limited wall intersections to odd rows and columns of the SketchPad.
