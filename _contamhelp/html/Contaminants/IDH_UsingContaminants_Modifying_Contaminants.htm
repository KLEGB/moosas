Modifying Species and Contaminants

Once you have created species for a project, you can modify any of the related parameters. This is done by using the Edit button from within the Species Properties dialog box that is accessed via the Data → Contaminants… menu item. ContamW will allow you to change the name of an existing contaminant without affecting any of the currently associated sources, sinks, filters or kinetic reactions as they reference contaminants by an internal index created by ContamW.
