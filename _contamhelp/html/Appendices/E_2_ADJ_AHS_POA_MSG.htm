ADJ_AHS_POA_MSGTYPE

This message may be received by ContamX at any time while in the ready mode. Each message can be used to set the outdoor air fraction of AHSs. The IDs used here are those provided by AHS_INFO_MSGTYPE.

Message Header;

int num_ahs;          // total number of OA fractions to set

int id[num_ahs];      // index of each AHS to set

float value[num_ahs]; // outdoor air fractions
