JCT_INFO_MSGTYPE

Provides the number of junctions and the type of each junction. The index of the type[] array is used to set the temperature of the junctions via the ADJ_JCT_TEMP_MSGTYPE.

Message Header;

int num_jcts; // number of junctions in the PRJ file

int type[num_jcts]; // junction type: 0=junction, 1=terminal
