LEAK_INFO_MSGTYPE

Provides a list of only those duct junctions which have been defined via ContamW to have leakage. The id[] array provides the order in which airflow rates will be provided by ContamX via LEAK_FLOW_UPDATE_MSGTYPE. Currently leaks are not included when using ADJ_WPC_MSGTYPE., so ambient_index will be zero for all leaks.

Message Header;

int num_leaks;     // number of junctions with leaks in the PRJ

int id[num_leaks]; // index according to ContamX
