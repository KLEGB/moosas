TERM_INFO_MSGTYPE

Provides information on those junctions that are terminal types. The id[] array provides the order in which airflow rates will be provided by ContamX via TERM_FLOW_UPDATE_MSGTYPE. If the ambient_index is 0, this terminal is not an infiltration point. Otherwise, ambient_index specifies the order in which terminal concentrations are to be sent to ContamX using ADJ_WPC_MSGTYPE.

Message Header;

int num_terms; // number of duct terminals in the PRJ

int id[num_terms]; // for each terminal: index according to ContamX

int ambient_index[num_terms] // for each terminal: 0/1 = not connected / connected to ambient

float x[num_terms]; // for each terminal: absolute coordinates [m]

float y[num_terms];

float z[num_terms];
