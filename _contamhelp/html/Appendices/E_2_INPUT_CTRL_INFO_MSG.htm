INPUT_CTRL_INFO_MSGTYPE

Provides number of control input nodes and the initial value of each node at the start of the simulation. Control input nodes are defined via ContamW by providing Constant type control nodes with a name. The values of these control nodes can be modified during simulation via the ADJ_CTRL_NODE_MSGTYPE.

Message Header;

int num_nodes; // number of control input nodes in the PRJ file

int id[num_nodes]; // index of control nodes according to ContamX

float init_vals[num_nodes]; // initial values of control input nodes

char* name[num_nodes]; // input node names (null-terminated strings)
