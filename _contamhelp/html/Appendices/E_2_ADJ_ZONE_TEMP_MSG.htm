ADJ_ZONE_TEMP_MSGTYPE

This message may be received by ContamX at any time while in the ready mode. Each message can be used to set the temperature of multiple zones. The IDs used here are those provided by ZONE_INFO_MSGTYPE.

Message Header;

int num_zones;          // number of zones to set

int id[num_zones];      // list of zone indexes

float value[num_zones]; // temperatures [K]
