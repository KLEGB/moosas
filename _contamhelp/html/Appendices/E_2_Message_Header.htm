Message Header and Message IDs

The message header is the first part of every message. It provides a consistent means of establishing the specific information that is to follow. The specifics will depend on the type field of the message. The length field includes the length of the header and the specific portion of the message that follows. The version field is provided to enable programs that utilize the socket communication capabilities of ContamX to ensure conformity to the messaging requirements as they evolve due to modifications/enhancements of the methodology.

char pattern[8]; // string to verify the header ‘ACATMSG’.

int length;      // length of entire message in bytes

int type;        // type of message (see table below.)

int version;     // current message version # = 10
