ADJ_JCT_TEMP_MSGTYPE

This message may be received by ContamX at any time while in the ready mode. Each message can be used to set the temperature of multiple junctions. The ids used here are those provided by JCT_INFO_MSGTYPE.

Message Header;

int num_jcts; // number of junctions to set

int id[num_jcts]; // list of junction indexes

float value[num_jcts]; // temperatures [K]
