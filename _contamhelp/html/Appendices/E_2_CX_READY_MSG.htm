CX_READY_MSGTYPE

This message will be sent by ContamX to indicate that it is in the ready mode and is prepared to receive messages through the bridge. This will occur for the first time after ContamX has finished sending all of the project information messages, performed the steady state initialization calculation and sent all of the simulation result messages (_UPDATE_MSGTYPE). It will be sent again after each CX_ADVANCE_MSGTYPE has been handled and the simulation result messages have been sent as requested via the option flag of CX_ADVANCE_MSGTYPE.

Message Header;

int time; // time of day in seconds at which ContamX performed its most recent calculation
