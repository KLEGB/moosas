Filter Element Types

These are the filter element types or models that you can implement with CONTAM. Refer to the related information for each specific model for detailed descriptions.

Constant Efficiency Filter: Define constant efficiencies for each user-selected species.

Simple Particle Filter: Define filter efficiency as a function of particle size, for example a MERV curve.

Simple Gaseous Filter: Define filter efficiency as a function of filter loading for a user selectable set of species.

Penn State UVGI Filter: Define an ultra-violet germicidal irradiation filter.

Super Filter: This enables the combination of multiple filter elements into a single filter, e.g., a packaged filter that includes a gaseous filter and a pre-filter that filters particles.
