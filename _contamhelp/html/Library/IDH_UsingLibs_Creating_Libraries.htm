Creating Libraries

Using the CONTAMW Library Manager, you create new libraries one of two ways. You can either save an existing library under a new name using the "Save As…" button, or use the "New" button of the Library File section of the CONTAMW Library Manager dialog box. The "Save As…" method makes a copy of the currently displayed library file under a new name, but maintains the original file. The "New" method clears the data currently displayed and allows you to start with an empty library file.
